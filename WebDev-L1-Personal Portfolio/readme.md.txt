# 💻 Personal Developer Portfolio

**Oasis Infobyte Web Development & Designing Internship — Task 2, Level 1**

---

## 📌 Project Overview
A clean, modern, and personal developer portfolio website designed to present skills, academic background, web development projects, and contact information in an organized, single-page layout.

---

## 🎯 Objectives
- Design a personalized interactive web portfolio.
- Present web development skills and featured projects with live links.
- Integrate an interactive contact form for user queries.
- Ensure cross-browser compatibility and seamless mobile responsiveness.

---

## 🛠️ Tools & Technologies
- **Frontend:** HTML5, CSS3, JavaScript
- **Icons & Fonts:** FontAwesome / Google Fonts
- **Editor:** Visual Studio Code
- **Version Control:** Git & GitHub

---

## ✨ Key Features
- **Hero Section:** Introduction banner with dynamic text and social media links.
- **About Me:** Professional overview highlighting experience and development background.
- **Skills Matrix:** Categorized breakdown of frontend, backend, and core programming skills.
- **Projects Showcase:** Interactive card grid displaying ongoing and completed projects with GitHub links.
- **Contact Form:** Clean input form allowing users to get in touch directly.
